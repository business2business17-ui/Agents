# Кто за что отвечает: 4 агента

| # | Агент (плагин) | Задача | Вход | Результат |
|---|---|---|---|---|
| 1 | **amazon-product-intelligence** | Сбор данных о товаре: ТТХ, сопоставление, тексты, SEO, цены; готовит пакет для Feed | XLSX/CSV/Google Sheet с товарами, GTIN, выгрузка Cerebro/Magnet (XLSX) или Helium 10 MCP, ваши цены, себестоимость, комиссии | Запечатанный пакет для Feed (`READY…` / `NOT_READY…`), review XLSX (12 листов), расчёт маржи/цен |
| 2 | **amazon-feed-compiler** | Заполняет Feed Amazon | Пакет от агента 1 + оригинальный шаблон `.xlsm` | Заполненный `.xlsm` (только Template с 7-й строки, остальное без изменений), dry run, аудит, манифест |
| 3 | **amazon-feed-error-agent** | Исправляет ошибки уже загруженного Feed | Processing Report + Feed | План исправлений (Change Plan); правки вносятся только после вашего подтверждения; сравнение отчётов до/после |
| 4 | **amazon-creative-studio** (Design) | Вёрстка дизайна, ТЗ дизайнеру, помощь в визуальном контенте | Данные о товаре, картинки (свои, референсы, скриншоты), ссылки Google/Amazon | Production XLSX, ТЗ дизайнеру, промпты для генераторов, проверка изображений, ZIP для загрузки |

## Что делает каждый подробнее

**1. Product Intelligence** — собирает ТТХ и приводит к фактам с единицами; сопоставляет строки и GTIN (контрольная цифра); пишет тексты (title, bullets, description, search terms) на языке страны с проверкой запрещённых слов и claims; строит SEO из Cerebro/Magnet или Helium 10 MCP (очистка, тиры 1–4, проверка страны и языка выгрузки); считает цены (Sale → Standard → Business, ступени по количеству и границы B2B — ваши решения), маржу (referral/FBA/MFN fee), GMV, ACOS, TACOS, ROAS, рекламный бюджет. Спрашивает категорию, тип товара, страну и язык; ищет в интернете свежие требования (комплаенс, категории, ограничения).

**2. Feed Compiler** — берёт только проверенный пакет; пишет в шаблон через XML-патч (макросы и другие листы не меняются), проверяет значения по настоящим выпадающим спискам шаблона; режим SIMULATION_MODE для пробного прогона; выдаёт статус и манифест файлов.

**3. Feed Error Agent** — разбирает Processing Report, сопоставляет ошибки с базой (`error_kb.json`), готовит Change Plan (что менять, в каких ячейках, почему), после вашего «ok» вносит правки и сравнивает отчёты.

**4. Design** — план визуального контента (карусель MAIN + 2–7, A+, Brand Story, Store, реклама, видео), тексты и локализация, ТЗ дизайнеру, промпты для ИИ-генераторов, проверка файлов (размеры, MAIN на белом фоне, вес). **Читает картинки**: свои фото товара, референсы конкурентов (только как ориентир, без копирования), мудборды, скриншоты. Реальный товар не перерисовывается (Product Fidelity Lock).

## Что общее у всех агентов

- **Один чекпоинт вместо россыпи вопросов**: ответ `ok` или правки по номерам. Вопросы только по блокерам, одним сообщением, с готовым рекомендованным ответом.
- **Режимы:** `AUTOPILOT` («делай сам»), `SMART` (по умолчанию), `GUIDED` (подтверждение каждого этапа).
- **Память проекта** (`amazon-project/PROJECT.md`, `creative-studio/PROJECT.md`): категория, тип товара, страна, язык, решения, заметки исследований — ничего не объясняется дважды.
- **В начале каждого проекта спрашивают**: категория и тип товара (по группам, с рекомендацией), страна (любой маркетплейс Amazon) и язык листинга.
- **Свежие данные из интернета**: комплаенс, категории, ограничения, спецификации — по официальным источникам нужной страны, с датой и ссылкой (`references/live-research.md`).
- **Ссылки**: Google Doc / Sheet / Slides / Drive (только чтение) и ссылки Amazon любой страны — категория или ASIN (`google_link.py`, `amazon_link.py`). Страницы Amazon не скрейпятся: данные идут через Helium 10 MCP, официальные API или страницу, которую вы открываете сами.
- **Честные статусы** `READY…` / `NOT_READY…` с точными причинами.

## Как агенты связаны

```
Product Intelligence → (пакет для Feed) → Feed Compiler → (загрузка в Amazon) → Feed Error Agent
                    ↘ (тексты, TTX, SEO) → Design (ТЗ, визуал)
```

Design работает самостоятельно и может брать готовые тексты, ТТХ и SEO-ключи из пакета агента 1.

## Какие агенты в каких ветках / как ставить

- Все четыре плагина в `main` после слияния PR (маркетплейс `.claude-plugin/marketplace.json`).
- Локально: `install.sh` / `install.ps1` (см. `docs/LOCAL_INSTALL.md`). В другие ИИ: `dist/<агент>/` (`system-prompt.md`, `instructions-short.md`, `knowledge/`).
